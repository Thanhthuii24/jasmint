# Jasmint - Personal Blog & Academic Portfolio

Welcome to my personal blog and portfolio! This site is built with Next.js 14, TailwindCSS, and MDX.

**Live Website:** [https://thanhthuii24.github.io/jasmint/](https://thanhthuii24.github.io/jasmint/)

## Local Development

1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npm run dev` to start the development server at `http://localhost:3000`

## Adding Content

All content is managed via Markdown (`.mdx`) files in the `content/` directory:
- To add a new blog post, create a `.mdx` file in `content/blog/`
- To add a new note, create a `.mdx` file in `content/notes/`

The site will automatically parse the frontmatter and render the Markdown content.

## Deployment

The site is automatically deployed to GitHub Pages via GitHub Actions whenever changes are pushed to the `main` branch.
